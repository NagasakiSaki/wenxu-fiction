## 2. 需要真机确认的清单

每条都请记录设备型号、系统版本、WebView 版本与输入法，并在失败时截图。

### 2.1 窄屏与键盘

- [ ] 视口约 390 px 竖屏：进入工作台，标记断点后底色与竖线对齐同行文字。
- [ ] 键盘弹出后滚动正文：镜像层跟随 textarea，不错位、不遮住最后一行。
- [ ] 横屏切换：高度与折行重算，竖线仍在精确偏移处。
- [ ] 系统字体放大（110% / 130%）：镜像与 textarea 字号、行高一致。
- [ ] 夜间模式与版画风格各看一次：底色对比不影响阅读正文。

### 2.2 输入法、Emoji 与长行

- [ ] 中文输入法逐字输入与整句上屏后，断点列表数量不变。
- [ ] 在包含 Emoji 的段落标记断点：不能落在代理对内部，字符不残缺。
- [ ] 单段数十字的长行自动折行：底色覆盖整段折行区域，竖线位于精确字符处。
- [ ] 空行、纯空格行上标记：仍能定位与取消。
- [ ] 同一行多个断点：竖线按位置排列；点击其中一个只取消那一个。

### 2.3 持久化与恢复

- [ ] 取消后切换章节再返回：取消结果保持。
- [ ] 取消后刷新页面 / 重启应用：断点数量、列表和底色一致。
- [ ] 导出草稿备份再恢复：断点仍在，位置正确；公开作品与本地阅读副本不含该字段。
- [ ] 滚动到底部后点列表定位：正文与镜像一起滚到断点，列表不串章。

### 2.4 与其它编辑操作共存

- [ ] 重排章节：断点跟随所属章节；其他章节不受影响。
- [ ] 删除章节、拆分、合并：受影响的断点被清除，未受影响的保留。
- [ ] 撤销拆分 / 合并：操作前备份恢复原方案，断点与备份一致。
- [ ] 修改正文：本章旧断点被清除并提示；其他章不受影响。
- [ ] 一键智能分章：已标记的断点迁移到新章节，越界断点被丢弃且不报错。

### 2.5 安卓专项

- [ ] 覆盖安装 v2.3.1（不卸载）：旧草稿、阅读副本、断点、书签、进度都在。
- [ ] 离线状态下重复 2.1–2.4 的关键项（断网后重启应用）。
- [ ] `OfflineCreationTest` 增加一条断点高亮/取消用例，用真实触摸事件而不是直接改业务状态。

## 4. 已知限制

- 编辑正文后不会自动迁移断点，只清除当前章旧断点；稳定迁移需要先定义插入/删除跨断点的规则。
- 高亮按章生成镜像 HTML，接近 200 万字符时字符串处理耗时上升，手机端尚未做帧率测量。
- 镜像层尺寸依赖 `ResizeObserver`；极旧 WebView 缺少该 API 时不会报错，但高亮可能不随尺寸更新。
