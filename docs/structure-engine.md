# 文序结构引擎 3.0

维护者：NagasakiSaki。实现见 `src/chapter-analysis.js`、`src/structure-intelligence.js`、`src/heading-profile.js`、`src/work-health.js`、`src/chapter-worker.js` 和 `src/import-review.js`。

## 设计与本次贡献

文序在浏览器或安卓本机转换文档、分析结构并由作者校正。规则与结构分析为本项目独立实现，不使用大模型、云端推理或训练模型；不声称学术首创。

1. **整篇分析与分级证据**：保留既有的章节语义、Markdown/Word层级、连续编号和正文跨度规则。代码围栏、完成标记及正文引用仍受过滤。候选证据等级不是统计正确率。
2. **本书示例规则**：作者选择2–12个真实标题和最多12个反例，学习编号前后缀、括号、标题层级；无格式文本只采用短行长度和正文邻接线索。可直接点候选旁的“标题示例 / 正文反例”，也可输入转换后的行号。反例按规范化后的完整短行排除，不代表理解其语义。规则重新扫描生成方案，需确认导入，绝不直接覆写草稿。
3. **争议位置审阅**：独立短行作为未选候选；异常篇幅、跳号、重复正文和学习规则匹配加入待核对队列。支持只看尚未确认的位置、上下文和逐项确认。确认记录是作者的审阅状态，不会改变规则或模拟训练模型。
4. **目录—正文匹配**：仅在文档前段存在明确“目录 / Contents”标记、至少两个紧邻标题能与后面的正文标题匹配时归档目录。页码引导符可归一化。归档原文保留到草稿导入资料，不静默删除。缺乏这些条件仍保留并提示人工检查。
5. **卷—章—节结构**：中文卷/部、英文Volume/Part形成卷层；章节下的节标题形成导航子项。卷标题单独归档并保留到章节元数据，小节原文留在正文。作品详情、桌面及手机阅读目录展示分卷，节链接定位到所在正文段落。拆章继承卷归属，顺延编号遇下一卷停止；手动修改后再次加入书架或导出作品时刷新节锚点。
6. **整书体检**：检查编号、同卷重复标题、完全相同正文、绝对及相对异常篇幅。导入总览覆盖整批文件，工作台“整书结构体检”也支持已有草稿。篇幅图和问题项可定位章节，不自动修复或删改。
7. **原文覆盖核对**：将规范化源文的非空白字符分配到正文、原始标题和归档资料，并逐章精确比对源文对应正文顺序及内部空白。允许BOM去除、换行统一和正文首尾空白规范化。空标题、卷名、目录及分隔线等未进入可读正文的原文留在归档，计入核对。核对未通过时禁用确认导入。这个验证针对转换后的文字，不验证Word/PDF转换是否遗漏页面或图片。
8. **场景线索断点建议**：已有“按字数推荐断点”增加“篇幅 + 场景线索”，在目标篇幅附近优先场景分隔符、时间/视角转场词，再选择段落或句末。没有场景理解或地点实体识别；作者逐项勾选后才拆章，文字按UTF-16偏移逐字保留，并自动备份。
9. **离线与可迁移**：Worker执行分析，30秒超时，作品限1000章/200万字符。学习规则随 `wenxu-draft-v1` 草稿迁移；需主动选择才用于后续文档，不自动套用其他作品。公开作品导出不包含学习规则和导入资料。

## 使用入口

- 导入文档 → 检查 / 校正分章 → 点“标题示例”选至少两个 → 学习示例并重新扫描 → 检查分界 → 确认导入。
- 只处理争议位置：打开“只看尚未确认的争议位置”，根据上下文保留/取消分界，再点“确认此处方案”，最后重新分章。
- 已有草稿：工作台章节区 → 整书结构体检 → 点击图表或提示跳到相关章节。
- 无标题长文：正文编辑区 → 按字数推荐断点 → 推荐方式选择“篇幅 + 场景线索” → 生成并核对建议 → 确认批量拆章。

## 可复现验证

```sh
npm test
node scripts/benchmark-structure.mjs docs/structure-benchmark.json
```

22份合成样例位于 `benchmarks/structure-cases.mjs`，期望边界由样例作者显式标注。完整结果见 [structure-benchmark.json](structure-benchmark.json)：

- 18份纯自动样例中17份分界完全匹配，边界F1为0.96。
- 4份示例辅助样例在每份选择两个正例后均匹配；其中一份额外使用一个反例。报告独立列出示例选择数、反例数和仍需修正的边界数。
- 22份混合结果为21份完全匹配；保留“无编号无格式且未提供示例”的失败用例。不能把辅助分数当作纯自动正确率。
- 简单正则只作本脚本内的规则对照，不是对第三方项目的评测。
- 约161万字符、1000章合成长文完整识别并通过正文覆盖核对。耗时及Node版本记录在报告，仅代表当次开发机运行，不是手机性能承诺。

此前82份维护者本地文档的解析回归是旧版验证记录，本次未重复运行，也不代表人工标注准确率。私有作品不提交仓库。Word/PDF转换、OCR和任意真实作品准确率不由合成标题行评测保证。

## 限制

无标记的短行既可能是章名也可能是旁白；示例只提供格式约束，必须人工核对。目录匹配不是通用排版恢复。场景建议不理解情节。没有OCR或云同步。图表最多预览120章，候选每页60条；完整分析覆盖作品范围。节导航每章最多显示100项，完整层级仍随作品保存。结构报告只含行号、类型和统计，不含路径、标题、正文或示例规则；不能代替原始文件和草稿备份。
