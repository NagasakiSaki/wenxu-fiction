# 本地创作应用与草稿互通

维护者：NagasakiSaki。v2.0.0 优先提供安卓 APK，同时提供 Windows 可安装的桌面 Web 应用（PWA）；当前没有 Windows EXE 或 iOS 安装包。

## 安卓安装与使用

在[正式版本](https://github.com/NagasakiSaki/wenxu-fiction/releases/latest)下载 `wenxu-android.apk`。支持 Android 8/API26 及以上，要求系统 WebView 至少119版；建议更新系统 WebView。APK内置编辑器、结构引擎、Worker、DOCX/PDF转换与本地字体/CMap/WASM资源，不以远程网站作为启动页面，也不需要登录。安装后第一次启动即可离线创作。

1. 打开应用，进入作者工作台，导入文档或新建草稿。
2. 安卓系统文件选择器支持单文件、多文件和文件夹。文件夹通过 Storage Access Framework 读取，不申请整个存储空间权限；保留子文件夹路径并沿用自然排序和导入预览。
3. 写作、自动分章、人工分界校正、光标拆章、批量拆章、字数建议、合并撤销、阅读与书签均使用共用功能代码。
4. “备份当前草稿”打开系统“另存为”，选择你自己的文件保存位置。导出不直接发送给任何人。
5. 更新同一签名、同一包名的 APK 时直接安装更新。卸载应用或清除其应用数据会清除私有草稿，请提前导出备份。

安卓草稿使用应用私有 Data 文件目录保存，不放在临时缓存。每次保存先写不可变正文快照，最后通过索引文件原子替换提交；拆分前备份和新草稿由同一索引提交，失败不替换已提交版本。旧快照在新索引提交后清理；操作前独立备份可在草稿箱找到。退出或切换应用时触发保存，正常输入仍约700毫秒自动保存。

## Windows 安装与离线

使用 Edge 或 Chrome 访问[本地应用页面](https://nagasakisaki.github.io/wenxu-fiction/#/app)，选择“安装桌面 Web 应用”，或使用浏览器菜单中的“安装此网站为应用”。安装入口由浏览器支持情况决定，内嵌浏览器通常不提供安装按钮。

首次保持联网，等待“离线资源已准备好”。编辑、导入格式转换、分章和备份所需资源均被预缓存；缓存完成后可断网重新启动。首次准备前、缓存被手动清除后，仍需联网重新准备。草稿保存在该浏览器用户资料的 IndexedDB 中。

有更新时不会在打字过程中自动重载：进入“本地应用”，点击“保存草稿并更新应用”。离线书库随应用资源版本更新；最新公开作品请联网访问网页版。当前 PWA 不等同于独立 EXE 安装包。

## 文件互通：网页 → 安卓 → 网页

两端都使用稳定格式 `wenxu-draft-v1`，v1.1及更早导出的同格式草稿也能恢复。

1. 网页或应用工作台点击“备份当前草稿”，导出 `<作品编号>-draft.json`。
2. 通过数据线、文件传输或自行选择的渠道，将文件传到另一设备。
3. 在另一端点击“恢复作品文件”，选择该 JSON。
4. 系统保留作品编号、书名、作者、简介、章节、正文和顺序，并为导入内容创建独立的本机草稿槽位。原草稿不会被覆盖。

未完成作品、空章节和空草稿均可备份；不需要为了换设备先填写笔名或发表。导出文件另含时间和来源平台。恢复前检查字段、章节数和正文容量；草稿文件最多32MB。正文仍限200万字符、1000章。

这是一种手动迁移，不是实时双向同步。两台设备同时修改同一作品时，不会自动合并；可参考导出时间并把两个版本分别保留。文件含正文与资料，请按自己的需求保存。阅读书签/历史用单独的阅读备份迁移，草稿文件不包含设置和书架。

## 多断点与字数建议

- 在正文中移动光标，点击“标记当前断点”，重复标记多个位置，再打开“批量拆章”。
- 预览并勾选需要的断点，确认后一次生成连续章节，后文按同类编号顺延；原文所有字符保留。
- 编辑正文会清除尚未应用的断点，避免旧位置指向错误文字。切换章节或刷新也不保留未确认断点。
- “按字数推荐断点”接受每章200–20000目标字符，优先段落、其次句末，不硬切无标点长句。目标只是篇幅参考，不分析情节。可逐个取消建议并查看各章开头及长度。
- 拆分结果仍受容量上限约束；每次确认都有操作前备份，也能在当前会话撤销最近一次结构操作。

## 开发与签名

```sh
npm ci
npm test
npm run build             # 网页 + PWA，输出 dist/
npm run build:native      # 本地资源包 + Capacitor 同步，输出 dist-native/ 和 android/
```

安卓编译使用 JDK21、Android SDK36、项目 Gradle Wrapper。应用标识 `io.github.nagasakisaki.wenxu`。CI工作流 `.github/workflows/android.yml` 构建所有者签名的 release APK，并运行模拟器上的离线创作和文件系统测试。工作流只在维护分支的相关代码改变时运行，不把签名材料上传为构建产物。

仓库使用 `ANDROID_KEYSTORE_BASE64` 和 `ANDROID_KEYSTORE_PASSWORD` 两个 Actions secrets。当前所有者的签名密钥及密码保存在本机被 Git 忽略的 `.private/` 目录，应单独妥善备份；不要上传到仓库。其他开发者应生成自己的签名材料，无法用自己的密钥覆盖安装所有者签名版本。

原生平台不注册 Service Worker，避免影响 Capacitor 桥接；网页采用更新确认式缓存。核心算法与草稿文件格式共用，保存和文件选择通过平台适配层实现。没有远程模型、分析跟踪或后台草稿上传。

引用与开源依赖见 [REFERENCES.md](../REFERENCES.md)。完整测试范围与实际结果以对应 Release 说明为准；模拟器通过不代表所有厂商系统均已真机验证。


## v2.1 本地书架

手机离线流程：工作台导入 TXT / MD / Word / 文字 PDF → 校正章节 → 点击“存入本地书架并阅读” → 我的书架。安卓内置资源，不需要联网或 GitHub。浏览器/PWA 首次缓存完成后可离线使用。

本地书架支持直接导入文序作品 JSON 和 `wenxu-draft-v1` 草稿文件。空章节需先在工作台补齐正文；未填笔名以“未署名”显示。书架保存完整阅读副本，编辑草稿不会自动改变它，再次存入同编号作品时更新；阅读 ID 保持稳定。书签、字体、翻页和阅读历史沿用现有阅读器。作品详情可以导出便携作品 JSON，在另一设备直接导入阅读或在工作台恢复编辑。文件传输需用户自行完成，不自动同步。

安卓书架使用应用私有 `books/index.json` 和不可变正文快照，先写正文再原子替换索引，与 `drafts/` 分开。网页书架使用独立 IndexedDB `wenxu-local-books`，不占用小容量 localStorage 正文空间。系统卸载/清理应用数据、浏览器清理站点数据会删除本地内容，请导出备份。
