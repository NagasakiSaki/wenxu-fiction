# 阅读器与多作品草稿箱

## 阅读器

- 每章顶部、底部都有上一章、作品目录和下一章；首尾章显示边界状态。
- 滚动模式按正常页面阅读；左右翻页模式用 CSS 多栏按可视区域分页，在一章内部逐页移动，章末继续前往下一章。
- 正文区域的水平触摸手势、上下两组翻页按钮及键盘方向键共用翻页逻辑。小幅触摸、垂直滚动、文字选择和屏幕边缘的系统手势不会触发切页。
- 字号16–32px、宋体/黑体、行距1.6–2.6倍、日夜模式和阅读模式保存在当前浏览器。左右翻页模式保留最近章节的页码。
- 手机端提供可展开目录。翻页模式收起站点页头页脚，将阅读区适配到屏幕；字号、字体和窗口尺寸变化后重新计算页数。

实现文件为 `src/reader-controls.js`、`src/experience.css` 和 `src/paged-reading.css`。网页的分页受浏览器字体和屏幕大小影响，不是纸质书的固定页码。

## 草稿箱

沿用 IndexedDB `wenxu-manuscripts` 的 `drafts` 存储，不升级数据库版本，不丢弃旧数据。每份草稿按独立 `draftKey` 保存，作品的公开 `id` 不用来区分草稿版本。保留 `current` 以兼容旧草稿，另外保存 `draft:<key>` 正文记录及 `summary:<key>` 列表摘要，草稿列表不必一次加载所有长篇正文。

- 新建和打开其他作品之前先保存当前草稿。
- 搜索、打开、复制、草稿文件备份、恢复和回收站均在当前浏览器执行。
- 副本使用新作品编号，便于作为独立作品发布；从备份恢复使用新草稿槽位，不覆盖已有草稿。
- 清空全部章节需要在页面确认，先建立独立的「清空前备份」，再将当前章节设为空数组；可从草稿箱打开备份恢复。书名、作者和简介保留。
- 回收站仅作可恢复的标记，不永久删除；正在编辑的草稿不能直接移入回收站。
- 输入停止约700毫秒后自动保存，手动保存会等待 IndexedDB 事务完成。切换草稿时取消旧草稿待执行的保存任务。

未完成的草稿可导出 `wenxu-draft-v1` 备份文件，允许缺少笔名或尚无章节；公开作品 JSON 继续执行完整的发表校验。`draftKey` 不写入公开作品文件。

草稿、设置及阅读位置不跨设备同步；清理浏览器数据会清除本机草稿。重要作品应另行导出备份。公开发布仍由 GitHub 仓库权限控制。

## 验证

`npm test` 覆盖翻页计算、手势方向与误触过滤、设置范围、章节首尾导航、草稿隔离、回收站恢复、清空备份和未完成草稿备份格式。浏览器检查还需覆盖手机布局、字号变化后的分页、页码刷新恢复、多份草稿切换，以及清空后的恢复流程。
